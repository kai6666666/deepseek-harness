怎么加群
  1. 用另一台设备上的手机 QQ「扫一扫」扫上面的二维码。
  2. 或者打开 QQ → 右上角「+」→ 加好友/群 → 搜群号，粘贴上面的群号。
  3. 群号是纯数字，长按选不中（本插件禁用了全局选中），所以用右边的按钮复制。
反馈问题的小建议
  • 说清楚「哪一步、期望什么、实际什么」，比只说「用不了」好定位得多。
  • 设置页里「运行日志」能导出会话记录，贴上来最有用。
  • 顺带说下机型和系统版本（例如「小米 13 / MIUI 14」），很多问题只出在特定机型上。
