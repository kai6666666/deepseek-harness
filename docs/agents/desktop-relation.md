## 与 DSH 桌面端的关系

引擎版本以**桌面端实际安装的版本为准**（当前 `0.2.0-rc.2`），来源是
`Y:\DSH\resources\app.asar` → `dsh/package.json`。
`C:\Users\你的用户名\.dsh\profiles\node_modules\@deepseek-ai\` 是旧版（`0.1.6-alpha.1`），
**不是权威来源**，别拿它当版本依据。
