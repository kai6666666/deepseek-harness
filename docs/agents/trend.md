## 判读

- **ΔAPK**：相对上一个版本的体积变化，突增通常意味着资源或依赖被带进来。
- **Δ取证**：相对上一个版本的取证耗时变化，连续变慢先怀疑设备负载或 CDP 超时。
- **代码**：`同码` = client 字节数与上一版完全相同，仅版本号/文档变化；`新码` = client 真实改动。
- **轮次 / 重试**：`1 / r0` 表示首轮一次通过；出现 `2` 或 `×2` 说明重试救过一次。
- **漂移 / 状态**：`0/9 · ✅` 干净；`·fixK` 自愈、`·chgN` 发布期变更、`·waitN` 等待期扰动，`⚠` 表示过程被操作过。
- **稳定**：`✅` 表示同版本二次取证与首轮九项一致；`⚠` 不一致；`—` 未跑 `--reverify`。
