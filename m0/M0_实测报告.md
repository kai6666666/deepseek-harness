## 2. 安装实测

```bash
npm config set registry https://registry.npmmirror.com
npm install -g @deepseek-ai/dsh@0.2.1-rc.2
```

| 指标 | 结果 |
|---|---|
| 包数 | 613 |
| 耗时 | 2~3 分钟（第二次重装 2 分钟） |
| 退出码 | 0 |
| `dsh --version` | 0.2.1-rc.2 ✅ |

### ⚠ 新坑：npm 11 的 allow-scripts 策略

首次安装出现警告，**5 个 install 脚本被静默跳过**：

```
@deepseek-ai/dsh-subprocess-local  (postinstall: ensure-spawn-helper.mjs)
koffi@3.1.1                        (install: cnoke prebuild)
node-pty@1.2.0-beta.15             (install: prebuild || node-gyp rebuild)
@google/genai@2.21.0               (preinstall)
protobufjs@7.6.6                   (postinstall)
```

后果：`/usr/lib/node_modules` 下**没有任何 node-pty 的 `.node`**（脚本没跑）。
但 **node-pty 自带预编译**：`prebuilds/linux-arm64/pty.node`（69,112 B），实测可用：

```
DATA:PTY_OK
exit 0
```

**结论：不需要 gcc/g++/make/python3，不需要 node-gyp，原方案的「避坑指南第 4 条」作废。**

若要在打包时彻底避免这个坑：

```bash
npm install -g @deepseek-ai/dsh@0.2.1-rc.2 \
  --allow-scripts=@deepseek-ai/dsh-subprocess-local,koffi,node-pty,@google/genai,protobufjs
```

## 3. 启动实测

```bash
DSH_HOME=/root/dsh-m0/home dsh web --no-open --port 3080
```

| 指标 | 实测值 |
|---|---|
| 冷启动到打印授权 URL | **约 45 秒** |
| 常驻内存 RSS | **约 411 MB**（411,564 KB） |
| URL 形态 | `http://127.0.0.1:3080/?token=<43 字符 base64url>` |

### 鉴权（最关键的三条）

| 请求 | 结果 |
|---|---|
| `GET http://127.0.0.1:3080/`（裸 origin） | **401** ❗ |
| `GET <授权URL>` | **303 See Other**，`location: ./` |
| 同一请求的响应头 | `set-cookie: dsh-auth-VPhEEcLKeqRDBoBalzN2Nm7CnfxKhLE00pKIDWxt1sw=v1.<payload>.<sig>; Max-Age=2592000; HttpOnly; SameSite=Strict` |
| 带 cookie 跟随 | **200**，37,512 bytes HTML |

对 Android 外壳的三条硬约束：

1. **禁止硬编码 origin**：裸 origin 直接 401，必须解析 stdout 的 `dsh web: <URL>`。
2. **cookie 名带每安装随机后缀**（`dsh-auth-VPhEEc...`），无法预置，每次都要走 token 交换。
3. **cookie 是 `HttpOnly` + `SameSite=Strict` + 30 天 Max-Age**：WebView 里必须
   `CookieManager.getInstance().setAcceptCookie(true)`，并在 `onPause`/退出前
   `CookieManager.getInstance().flush()`，否则进程一死登录态就丢。

## 5. 对前几轮结论的修正

| 曾经的判断 | 实测 | 结论 |
|---|---|---|
| 「node-pty 必须 arm64 现场编，要 build-essential + python3」 | 包内自带 `prebuilds/linux-arm64/pty.node`，require 即用 | **撤回** |
| 「xz 解压分钟级，换 zstd」 | 61 MB `.tar.xz` 全流解压 6 秒 | **撤回**（xz 不是瓶颈） |
| 「必须用 token URL，不能硬编码 origin」 | 裸 origin 401，token→303→cookie | **成立，实测** |
| 「PRoot 的 loopback 与宿主互通」 | 容器内 127.0.0.1:3080 与手机同栈 | **成立**（手机浏览器可直接访问） |
| 新增 | npm 11 `allow-scripts` 会吞掉 native 安装脚本 | **原方案未覆盖的坑** |
