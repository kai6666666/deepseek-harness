# 调试与验证探针集合 (tools/probe/)

本目录归档在真机 UI 诊断与端到端验收中使用的探针脚本。

## 探针清单

| 脚本 | 描述 |
|---|---|
| `probe-lralign.js` | 验证会话页左上按钮与右上按钮在几何（rect/top/dyTop/dyH/dyW）、SVG 尺寸、内边距、display/position 属性上的严格一致性 |
| `probe170.js` | 抽屉在进入设置页时的行为探测（含遮罩层级、DOM 状态、MutationObserver 取证） |
| `probe177.js` | 同上系列的第 7 版迭代 |
| `probe180.js` | 头部栏高度对齐、DOM 结构与图标样式的细粒度探测 |
| `probe185.js` | 头部栏高度对齐系列后续迭代 |
| `probe186.js` | 按钮边距、位置与主界面 UI 边界核验 |
| `probe187.js` | 左按钮移入 header 布局与双图标消除的阶段性验收探针 |
| `probe188.js` | 深度探测非会话页面（插件/设置/智能体）的 header leading 元素状态及汉堡按钮回退逻辑 |
| `probe190.js` | 多模态齿轮图标展示与 SVG 选择器适配探测 |

## 使用方式

将目标探针脚本追加或注入到调试页面的 client bundle 或执行环境：

```sh
cat tools/probe/probe-lralign.js >> client.js
```

## 清理记录（2026-11-24）

做了**引用审计**：对仓库内 442 个可读文本文件逐个搜索 `tools/` 下每个脚本的路径与文件名，
判定「无任何文件引用」的共 18 个。其中 10 个是**已完成使命的一次性取证探针**，已删除
（git 历史里永久可查）：

| 已删除 | 为什么 |
|---|---|
| `probe171.js` ~ `probe176.js` | 抽屉/设置页取证系列，问题已修（v7 起改成 CSS 首帧生效），这些版本不再需要 |
| `probe181.js` ~ `probe184.js` | 头部栏对齐系列，结论已固化进 `docs/agents/mobile-ui.md` |

**保留判据**：只要还被别的文件提到（哪怕是文档），就留着 —— 说明它仍有解释价值。
`probe170.js`（首个取证脚本，注释里自带方法论）和 `probe-lralign.js`（几何一致性验收）
都是因为这个理由保留。

**未删除的「无引用」脚本**：`probe-vmos.mjs`、`ui-drive.mjs`、`ui-standalone.mjs`、
以及 4 个 `uiagent-*` —— 它们是**手动工具**而非一次性探针，判断记录在
`tools/legacy/README.md`。

**写新探针的约定**：

1. 文件头写清「目的 / 输出通道 / 采样点」，像 `probe170.js` 那样。
2. 一次性问题在注释里标 `（临时，取证后即删）`，修好后按本次流程清理。
3. 已经被文档吸收的结论，不要靠探针保存。
